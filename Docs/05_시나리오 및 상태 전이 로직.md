# 시나리오 및 상태 전이 로직 (Scenario & State Transition Logic)

이 문서는 Aegis-AI : DAS의 **Scenario Injector(Tab 4)**에서 사용할 사전 정의 시나리오 10개를 정의합니다.
각 시나리오는 Context Tool 값을 일괄 주입한 뒤, MockInferenceEngine(또는 FunctionGemma)이 추론하여 Action Tool을 호출하는 흐름을 따릅니다.

## 공통 구조

```
1. Context 값 일괄 업데이트 (contextOverrides → ViewModel)
2. InferenceEngine.infer(appState) 호출
3. 결과 ActionCall 목록을 즉시 실행 → Action Tool 상태 반영
4. Thinking Log(Tab 3)에 thought/rawInput/rawOutput 기록
```

### 심각도(Severity) 기준

| Severity | 의미 | UI 매핑 |
| :---: | :--- | :--- |
| 0 | 정상 | 기본 상태 유지 |
| 1 | 주의 | Amber 계열 경고 |
| 2 | 위험 | Red 계열 경고 + 물리 제어 |
| 3 | 치명 | Red 점멸 + 긴급 제어 + e-Call 가능 |
